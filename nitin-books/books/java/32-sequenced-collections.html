Q1. What's the criterion for putting these interfaces at this specific place? Why were Queue and PriorityQueue left out?

Any collection which follows the conditions below can be termed sequenced:

  1. Predictable iteration: elements are returned in a consistent and well-defined order every time we iterate. So if a collection maintains elements in insertion order, or sorted order (ascending or descending), it follows predictable iteration.
  2. The collection provides support to access or manipulate the first and last element.
  3. The collection supports a reversible view.
  • Queue follows FIFO: we can access the first element but not the last. So ✗ (a reversible view is also not supported directly).
  • PriorityQueue fails all three conditions ✗. HashSet also fails ✗.

Q2. Why is LinkedHashSet put under SequencedSet and not directly under SequencedCollection?

Because SequencedSet adds an additional contract: NO DUPLICATES.

Q3. Why do we need them? What gap are we trying to fill?

If we observe the collections which are sequenced, we will find that they all offer get first / get last, add (first/last), remove (first/last) and a reverse view of the collection. But there was no common interface: each collection had its own method names, which is difficult to remember. That's one of the gaps which these fill.

List<Integer> list = new ArrayList<>(List.of(1, 2, 3));
list.getFirst();          // 1
list.getLast();           // 3
list.addFirst(0);         // [0, 1, 2, 3]
list.reversed();          // view: [3, 2, 1, 0]

LinkedHashMap<String,Integer> map = new LinkedHashMap<>();
map.put("a", 1); map.put("b", 2);
map.firstEntry();         // a=1
map.putFirst("z", 0);     // z moves to the front
Good to know
  • reversed() returns a view, not a copy: changes show through both ways.
  • Unmodifiable or fixed collections (e.g. List.of) throw UnsupportedOperationException on the add/remove methods; an empty collection throws NoSuchElementException from getFirst().
  • For TreeSet/TreeMap (sorted), addFirst/putFirst are unsupported, because position is decided by the comparator.
Interview corner
Why is Queue not SequencedCollection?

It only exposes the head, has no defined last-element access, and no reversed view.

What does SequencedSet add over SequencedCollection?

The no-duplicates contract of a Set.

Which version introduced these?

Java 21 (JEP 431).
