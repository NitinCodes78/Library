The Java Platform: JVM, JRE, JDK

How a .java file becomes something your computer can run, and what you actually install.

What is Java?

  • A platform independent language.
  • Portable: WORA, "Write Once, Run Anywhere", made possible by the JVM.
  • Object oriented (OOPS).

  • The Java program and the bytecode are platform independent.
  • The JVM is platform dependent. macOS and Windows each have their own JVM, and that is exactly why the same bytecode runs on both.

Compile: javac Student.java gives bytecode and creates Student.class.

You download a JDK by version: 21, 17, 8 and so on. A newer version has newer features in the JDK.

Your first program: the rules

  1. File name == class name (for the public class).
  2. One file, only one public class.
  3. main() is the starting point of the program, inside the public class.

Rules 1 and 2 also answer a question: how does Java know which class has main()? Because the public class has the same name as the file, so it knows where to look.

The JVM takes the bytecode and calls main():

public static void main(String[] args) {
    System.out.println("Hello, Java");
}
javac Employee.java     # compile
java Employee           # run

If we make any change in the .java file, we have to compile it again for the change to reflect.

Good to know
  • JIT compiler: instead of interpreting bytecode line by line forever, the JVM watches for "hot" code (called often) and compiles it to native machine code while the program is running. That is why Java gets faster after warm-up.
  • Why public static void main? public: the JVM must reach it from outside. static: the JVM calls it without creating an object. void: it returns nothing to the JVM. String[] args: command-line arguments.
Interview corner
Is Java platform independent? Is the JVM?

Java code (bytecode) is platform independent. The JVM is platform dependent: each operating system has its own JVM that understands the same bytecode.

JDK vs JRE vs JVM?

JVM runs bytecode. JRE = JVM + libraries, to run programs. JDK = JRE + compiler and tools, to build programs.

What is bytecode?

The intermediate instructions in a .class file produced by javac. It is not tied to any CPU.

What does the JIT compiler do?

It converts frequently executed bytecode into native machine code at runtime to speed up execution.
