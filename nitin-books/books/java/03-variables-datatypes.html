Variables and Data Types

What a variable can hold, how Java stores it, and what happens when you convert between types.

Java variables

  • Variable names are case-sensitive.
  • Java is a statically typed language: we have to define the data type, like int var = 5;
  • Java is a strongly typed language: each data type has a range, like int goes from −2³¹ to 2³¹−1.
  • Names can contain Unicode letters and digits, and can start with $, _ or a letter. Use camelCase.

Default values

A variable gets a default value only if it is a member of a class. A local variable inside a method has no default, and using it is an error.

class Employee {
    byte var;              // class member variable → gets default 0
    void func() {
        byte var1;
        System.out.println(var1);   // ERROR: variable might not have been initialized
    }
}

float and double: be careful

long  x    = 100L;
float val1 = .3f;
float val2 = .1f;
float val3 = val1 - val2;      // prints 0.20000002, not 0.2

float and double follow the IEEE 754 standard, which cannot represent most decimals exactly. Never use them if you care about the exact decimal value.

How are they stored? 
float a = .7f;
System.out.println((double) a);    // 0.699999988... not exactly 0.7

Don't use them in industry for things like currency. Use BigDecimal instead.

Type conversion

1. Widening

Automatic. Converts from lower to higher.

byteshortintlong

2. Down casting

Explicit. Higher to lower, you write the cast.

longintshortbyte

3. Promotion

Smaller types in an expression are lifted to int automatically.

1. Widening (automatic)

int  var = 10;
long varLong = var;       // converts automatically

2. Down casting (explicit)

int  var  = 10;
byte bVar = (byte) var;   // explicit cast

The byte range is −128 to 127. If var = 129, then bVar becomes −127: it goes around in a loop. Similarly −126 if var = 130.

127+1−128…129 → −127

3. Promotion

byte var1 = 127;
byte var2 = 10;
var1 + var2;      // Java takes this expression as int, out of byte range

So byte c = var1 + var2; will not compile without a cast. The sum is an int.

Static variables

Static variables are associated with the class. You can access them directly without an object.

class Employee {
    int var1;
    static int var2;     // class variable: not given to objects
}
// Employee.var2

Make two objects, obj1 and obj2. Each object has its own copy of var1, but for var2 there is just one copy, common to both objects.

Interview corner
Why is Java called strongly typed?

Every variable has a declared type with a fixed range, and the compiler checks types strictly. You cannot silently put a double into an int.

What is the default value of an int field? Of a local int?

A field defaults to 0. A local variable has no default; using it before assigning is a compile error.

Why does (byte) 129 give -127?

129 does not fit in 8 bits. The cast keeps only the lowest 8 bits, which as a signed byte is −127. It wraps around.

Why should you not use float or double for money?

They cannot represent most decimal fractions exactly (IEEE 754), so errors creep in. Use BigDecimal.

Is Java pass by value or pass by reference?

Always pass by value. For objects, the value copied is the reference, so the method can change the object's contents, but cannot make the caller's variable point to a different object.
