The Object Class and Nested Classes

The parent of every class, and classes that live inside other classes.

The Object class

Every class in Java, implicitly or explicitly, extends the Object class. It is the ultimate parent.

  • If a class does not extend another class, it automatically extends Object by default.
  • If a class does extend another class, it still indirectly extends Object through its parent: its parent will extend it.

Object provides methods such as equals(), hashCode(), toString(), getClass(), wait(), notify() and notifyAll().

Since it is the parent of all, we can store a reference of any class in an Object variable:

Object obj1 = new Person();
obj1.getClass();      // class Person

Nested classes

A class declared inside another class. A nested class's scope can't be more than the outer class.

Static nested class

  1. It doesn't have access to the non-static instance variables and methods of the outer class.
  2. Its object can be created without creating an object of the outer class.
  3. It can be public, private, protected or default.

It is associated with the class of the outer class, not the object of the outer class.

Outerclass.NestedClass nestedObj = new Outerclass.NestedClass();

Remember: a top-level class can be only public or package-private (default), never private or protected. A nested class can use any of the four.

Member inner class (non-static)

It needs an outer object first:

Outerclass outerClassObj = new Outerclass();
Outerclass.Innerclass innerObj = outerClassObj.new Innerclass();

Local inner class

  1. Defined in any block, like a for loop, an if-condition block, a method, etc.
  2. Only the default access modifier.
  3. Can't be instantiated outside this block.
void display() {
    class LocalInnerClass {
        // ...
    }
    new LocalInnerClass();      // only usable inside display()
}

Remember: if you want to invoke a method without creating the class's object, make that method static. Otherwise you get "Non-static method cannot be referenced from a static context".

Inheriting an inner class

One inner class can inherit another inner class in the same outer class.

Static inner class inherited by another class 
class OuterClass {
    static class InnerClass { }
}
class SomeClass extends OuterClass.InnerClass { }
If the inner class is not static 
class SomeClass extends OuterClass.InnerClass {
    SomeClass() {
        new OuterClass().super();     // important!
    }
}

As you know, when a child constructor is invoked, it also invokes the parent constructor. But here the parent is an inner class, so it can only be accessed through an object of the outer class (since it is non-static).

Anonymous inner class

An inner class without a name. It is used when we want to override the behaviour of a method for an abstract class or interface without even creating the subclass. The compiler generates a name for it internally (OuterClass$1.class).

Only one object can be created from an anonymous inner class, at the point of its definition.

Example 
public abstract class Car {
    public abstract void pressBreak();
}

// in main:
Car audiCarObj = new Car() {          // Audi object created without creating an Audi class
    @Override
    public void pressBreak() {
        // Audi's braking behaviour
    }
};
audiCarObj.pressBreak();
Interview corner
Which class is the parent of all classes?

java.lang.Object.

Static nested class vs inner class?

A static nested class needs no outer object and cannot touch the outer instance members. An inner class belongs to an outer object and can use its members directly.

Where are anonymous classes commonly used?

Quick one-off implementations of an interface or abstract class, like listeners or comparators. Since Java 8, lambdas replace most of them for functional interfaces.

Can an inner class access private members of the outer class?

Yes. Nested classes can access all members of the enclosing class, including private ones.
