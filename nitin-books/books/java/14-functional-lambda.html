Functional Interfaces and Lambdas

One abstract method, and a short way to implement it.

Functional interface

  1. If an interface contains only 1 abstract method, it is a functional interface (it can have other methods: default and static).
  2. Also known as SAM (Single Abstract Method) interface.
  3. The @FunctionalInterface annotation can be used at the top of the interface (optional). We get a compilation error if we try to add more than 1 abstract method.
@FunctionalInterface
public interface Bird {
    void canFly(String val);                 // the one abstract method

    static void canEat() { }                 // static: fine, not abstract
    String toString();                       // Object class method: not counted as abstract
}

The toString() line is an Object class method (like equals() etc. in Object), so there is no need to provide the implementation in the child class and these are not considered abstract, because by default every class extends Object.

Lambda expression

A way to implement a functional interface. It can also be implemented with the implements keyword or an anonymous class like any other interface, but the lambda expression is made for implementing functional interfaces.

Using an anonymous class

@FunctionalInterface
public interface Bird {
    void canFly(String val);
}

Bird eagle = new Bird() {
    @Override
    public void canFly(String val) {
        System.out.println("Eagle flies: " + val);
    }
};
eagle.canFly("high");

Using a lambda

Bird eagle = (val) -> System.out.println("Eagle flies: " + val);
eagle.canFly("high");
(val)  ->  System.out.println(val)
parameters    arrow    body

The compiler already knows the interface's single method, so you only write parameters and body. No class name, no method name, no @Override.

Good to know
  • One parameter: brackets optional (val -> ...). No parameter: () -> ....
  • Single-statement body needs no braces and no return. A block body uses { ... return x; }.
  • Built-in functional interfaces: Runnable, Comparator, Predicate, Function, Consumer, Supplier.

Shortening the syntax

Since there is only one abstract method in a functional interface, we can shorten the anonymous-class syntax: no need to tell which method to override.

Bird eagleObject = (String value) -> {
    System.out.println("Eagle impl..");
};                                      // no need for curly braces if there is only one line
eagleObject.canFly("Vertical");

Consumer: an operation that accepts a single input and returns no result. 
Consumer<Integer> loggingObject = (Integer val) -> {
    if (val > 10) System.out.println("Value is greater than 10");
};
loggingObject.accept(11);
Supplier: supplies a result, accepts no input. 
Supplier<String> isEvenNumber = () -> "this is ...";
isEvenNumber.get();
Function: accepts one argument, processes it and produces a result. 
Function<Integer, String> intToStr = (Integer num) -> {
    return num.toString();
};
intToStr.apply(64);
Predicate: a function that accepts one argument and returns a boolean. 
Predicate<Integer> isEven = n -> n % 2 == 0;
isEven.test(4);     // true

Functional interface and inheritance

Use case 1: a functional interface extending a non-functional interface

With @FunctionalInterface this gives a compilation error if the parent already has an abstract method: the parent's abstract method is carried to the child, so the child basically has 2. It works fine if the parent has only default methods (implementation already provided) or no abstract method at all.

Interview corner
Can a functional interface have default and static methods?

Yes, any number. Only the count of abstract methods matters: exactly one.

Why aren't equals() or toString() counted?

Every implementing class already inherits them from Object, so no one needs to implement them.

Lambda vs anonymous class?

A lambda works only for functional interfaces, has no own this (it refers to the enclosing class) and doesn't create a separate class file. An anonymous class can implement any interface or abstract class, and has its own this.
