Methods: static, final, abstract, varargs

How methods are bound, what static really means, and the rules for special kinds of methods.

Why overriding is called dynamic binding

Overriding is also called dynamic binding / runtime polymorphism.

Person obj = new Doctor();
obj.profession();

Here Java decides at runtime: if the profession() method is there in Doctor, it calls that, else the one in Person.

Static methods

  • Associated with the class. Can be called with just the class name, no need to make an object.
  • Cannot access non-static instance variables and methods.
  • Cannot be overridden.

Why can't they access non-static things? It doesn't make sense (Java is very logical). Static methods are called without objects, whereas objects are to be created for non-static methods. If a static method could call a non-static one, it would defy the non-static one's behaviour (which object would it work on?).

Why can't they be overridden? Again, they are associated with that class. No one has the right to do so.

Good to know
  • If a child class writes a static method with the same signature as the parent's, it is not an error, but it is method hiding, not overriding. The method called depends on the reference type, not the object.
  • A static method can use non-static members if it creates an object first (new Foo().bar()). It just cannot use them directly.
  • This is why main is static: the JVM can call it before any object exists.

Abstract methods

Defined in abstract classes (and, by default, in interfaces). Only the method declaration is done; its implementation is done in the child classes.

abstract class Shape {
    abstract double area();          // no body
}
class Circle extends Shape {
    double r = 2;
    double area() { return Math.PI * r * r; }
}

The rule to remember: a class with an abstract method must itself be abstract, or be an interface.

Variable arguments (varargs)

public static int sum(int... variable) {   // treated as an array (int[])
    int output = 0;
    for (int var : variable) {
        output += var;
    }
    return output;
}

sum(1, 1);
sum(2, 3);
sum(3, 4, 5, 6);
  • A variable number of inputs in the parameter. Inside the method it is an array, which is why the for-each loop works and why sum(new int[]{1,2,3}) is also a valid call.
  • Only one variable argument can be present in the method.
  • It should be the last argument in the list.
Interview corner
Can we override a static method?

No. A child can declare a static method with the same signature, but that hides the parent's one; it is not runtime polymorphism.

Why can't a static method use this or non-static fields?

It belongs to the class, not to any object, so there is no "current object" (this) to refer to.

Can you overload main()?

Yes, you can write other main methods with different parameters, but the JVM only starts from public static void main(String[] args).

Can a method have two varargs parameters?

No. Only one, and it must be last.
